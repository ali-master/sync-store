## Introduction

Sync Store synchronizes JSON values between app instances using an HTTP and WebSocket API.
The TypeScript client provides local caching, queued offline writes and reconciliation after reconnecting.

The API runs on Bun with MongoDB storage. Two clients share server data by user ID, while each instance maintains its own local cache and pending-operation outbox.

## Before production

Prisma 8 MongoDB support is early access. A shared API key does not authenticate individual users; use a trusted backend to enforce user identity. Realtime broadcasting currently requires a single API process, and delivery is at least once. Read the [security guide](/docs/guides/api-key-management) and [operational limits](/docs/guides/deployment) before deployment.
